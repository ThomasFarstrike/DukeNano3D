======================================================================
CONCLUSIONS
======================================================================
1. The best pipeline is pngquant → zopflipng.
   pngquant reduces the color palette (32->8, 83->13, 92->23 colors),
   then zopflipng applies aggressive DEFLATE + filter optimization on the
   smaller-indexed image.

2. Order is critical: pngquant must come before zopflipng.
   If zopflipng runs first, pngquant still reduces colors, but zopflipng
   wasted effort compressing a larger palette first.

3. optipng adds nothing after pngquant+zopflipng — the result is identical
   (zopflipng already explores all filter strategies).

4. zopflipng alone (without pngquant) preserves the full color palette and
   achieves ~58% savings. Adding pngquant first boosts this to ~71-75%.
